# Library Management System — Baseline

This is the **baseline version** of the Library Management System — a deliberately simple, limited application that serves as the starting point before AI-driven enhancements are applied in a later phase.

## Tech Stack

- **Backend:** Node.js + Express (TypeScript)
- **Database:** SQLite via the built-in `node:sqlite` module (requires Node.js >= 22.5)
- **Frontend:** Plain HTML + CSS + vanilla TypeScript (no framework, no bundler)
- **Port:** 5050

## Getting Started

```bash
npm install
npm run build
npm start
```

Then open [http://localhost:5050](http://localhost:5050) in your browser.

## Features

1. **Books** — Add books (title, author, ISBN) and view the full catalogue with availability status
2. **Members** — Add library members (name, email) and view the member list
3. **Issue Book** — Select an available book and a member to issue the book
4. **Return Book** — View all active loans and return a book with one click

## Project Structure

```
├── src/
│   ├── server.ts            # Express app, listens on port 5050
│   ├── db/database.ts       # SQLite setup via node:sqlite
│   ├── routes/
│   │   ├── books.ts         # GET/POST /api/books
│   │   ├── members.ts       # GET/POST /api/members
│   │   └── loans.ts         # GET /api/loans, POST /api/loans/issue & /return
│   └── client/app.ts        # Vanilla TS frontend (compiled to public/app.js)
├── public/
│   ├── index.html
│   ├── style.css
│   └── app.js               # Generated by tsc
├── dist/                    # Generated by tsc (backend)
├── tsconfig.json            # Backend TypeScript config
├── tsconfig.client.json     # Frontend TypeScript config
└── package.json
```

## Intentional Limitations

These gaps are deliberate — they will be addressed in a future enhancement phase:

- No due-date tracking on issued books
- No overdue detection or fines
- No search or filter functionality
- No authentication
- No input validation beyond required-field checks
- No reporting or analytics
- No pagination
